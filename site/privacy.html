Kobutai

Privacy Policy

Last updated: 11 October 2026

Kobutai is an open-source browser extension. The developer runs no servers and does not collect, receive or sell any user data. The extension has no analytics, tracking or ads.

The extension does not read page text, forms, cookies or your browsing history, and never sends full page URLs to anyone.

When it goes online, and to whom

Network requests happen only in these cases, and always straight from your browser:

  1. AI tagging (off by default). Only if you connect your own model provider on the “AI” page (API key, subscription sign-in or custom endpoint) and turn it on. What's playing is recognised by a small model built into the extension, on your device, and nothing is sent. Only for a new item the built-in model is unsure about are its title, artist and site domain sent to the provider you chose (for example OpenAI, Anthropic, DeepSeek, OpenRouter, or your own Ollama server) to work out the type and genre. That provider's privacy policy applies. Results are cached on your device, so the same item is never sent twice.
    • When connecting: subscription sign-in opens the provider's sign-in page and exchanges tokens with its authorisation server; expired tokens are refreshed with that provider automatically.
  2. Remote character library. Every 12 hours (30 minutes after a failure) the extension downloads characters from the libraries you subscribe to (by default the project's GitHub repository library/ folder on raw.githubusercontent.com). A library's pack.json may point to assets on other https addresses, which are then fetched too. No personal data is sent, but those servers see your IP address, as with any website.
  3. Petdex import. Only when you search or import on the settings page: the extension fetches the pet list from assets.petdex.dev, then downloads the assets of the pet you picked from the https addresses in that list.
  4. Cover art. The control bar shows the cover image provided by the site that is playing (https only). Your browser loads it from that image's server, without a Referer.
  5. Auto-match characters (off by default). Only when you turn it on. The extension checks the title and artist against a built-in rule table on your device; titles and artists are never sent anywhere. On a match with a character that hasn't been downloaded yet, it fetches the pet list from assets.petdex.dev (at most once a day) and that one character's assets. No personal data is sent, but Petdex's servers see your IP address and which character was downloaded, from which they could roughly infer that you're playing something related to it. Characters already downloaded don't trigger any request.

The built-in characters and the emoji used in bubbles ship inside the extension; showing them doesn't go online.

Sharing a character you drew sends nothing by itself: the extension saves a zip to your Downloads folder and, if you click, opens a GitHub page or your email app. You decide whether to send the file. If it's accepted, its name, your credit name and the sprite sheet are published in the project's GitHub repository under CC BY 4.0.

Permissions

  • storage: save the settings and data listed above.
  • alarms: wake the background once an hour to check whether the remote library needs updating.
  • Content scripts on all sites: show the floating character on any page, read that page's media state and carry out the controls you click.
  • Optional https://*/* and http://*/* host permissions: not granted by default. They're requested for one specific site only when needed:
    • adding a custom character library that doesn't allow cross-origin access: that one site;
    • connecting a model provider: its API and sign-in servers (for example api.openai.com, auth.openai.com); subscription sign-in also requests localhost / 127.0.0.1 to read the local address the provider redirects to after sign-in (the extension opens no local port);
    • adding a custom model endpoint: that one address (local servers are usually http://localhost).

Deleting your data

Removing the extension at chrome://extensions deletes everything it stored. You can also clear the tag cache and delete imported characters from the settings pages.

Questions and suggestions are welcome as GitHub issues: github.com/xingaobio/kobutai

プライバシーポリシー

最終更新日：2026 年 10 月 11 日

Kobutai はオープンソースのブラウザ拡張機能です。開発者はサーバーを運営しておらず、ユーザーのデータを収集・受信・販売することは一切ありません。アクセス解析・トラッキング・広告も入っていません。

ブラウザ内で読み取り・保存するもの

データ用途保存場所
再生中のメディア：タイトル、アーティスト、カバー画像の URL、再生位置、音量、サイトのドメインコントロールバーの表示、タブをまたいだ操作、コンテンツの分類メモリ上のみ。タブを閉じると消えます
オーバーレイの位置とサイズ（サイトごと）、キャラを隠すサイトの一覧、表示言語、共有時のクレジット名設定を覚えておくためchrome.storage.local（この端末）
アルバム（引いたキャラの ID と回数）、分類キャッシュ（コンテンツ → 種類／ジャンル）抽選とアルバムchrome.storage.local（この端末）
ロックしたキャラの ID同じ Google アカウントでログインしたブラウザ間で同期chrome.storage.sync（Chrome が同期。開発者は見られません）
現在の抽選結果、直近 50 件の再生内容（タイトル／アーティスト／ドメイン）に対応するキャラ、メインのメディアの順番バックグラウンド再起動後の復元、前の内容に戻ったときに同じキャラを出すためchrome.storage.session（ブラウザを閉じると消去）

追加した API キー、サブスクリプションのログイン情報（OAuth トークン）、カスタムのモデルエンドポイントと選んだモデル任意の AI 判定chrome.storage.local（この端末のみ、同期しません）

ページの本文、フォーム、Cookie、閲覧履歴は読み取りません。ページの完全な URL を誰かに送ることもありません。

通信するタイミングと送り先

ネットワーク通信が発生するのは次の場合だけで、すべてあなたのブラウザから直接送られます。

  1. AI 判定（初期状態はオフ）：「AI」ページであなた自身のモデルサービス（API キー、サブスクリプションのログイン、カスタムエンドポイント）を接続して有効にした場合のみ。再生中の内容は拡張機能に内蔵した小さなモデルが端末の中で判定し、何も送りません。内蔵モデルが迷った新しいコンテンツについてだけ、そのタイトル・アーティスト・サイトのドメインを、選んだサービス（OpenAI、Anthropic、DeepSeek、OpenRouter、自前の Ollama サーバーなど）に直接送り、種類とジャンルを判定します。そのサービスのプライバシーポリシーが適用されます。結果は端末にキャッシュされ、同じ内容を二度送ることはありません。
    • 接続時：サブスクリプションのログインではサービスのログインページを開き、その認可サーバーとトークンを交換します。トークンの期限が切れると、拡張機能がそのサービスで自動的に更新します。
  2. リモートのキャラライブラリ：12 時間ごと（失敗時は 30 分後）に、購読しているライブラリからキャラをダウンロードします（初期設定は本プロジェクトの GitHub リポジトリの library/、raw.githubusercontent.com）。ライブラリの pack.json がほかの https アドレスの素材を参照している場合は、そこにもアクセスします。個人データは含みませんが、ふつうのウェブサイトと同じく、相手のサーバーには IP アドレスが見えます。
  3. Petdex からのインポート：設定ページで検索やインポートをしたときだけ、assets.petdex.dev からキャラ一覧を取得し、選んだキャラの素材を一覧にある https アドレスからダウンロードします。
  4. カバー画像：コントロールバーには、再生中のサイトが提供するカバー画像（https のみ）を表示します。その際ブラウザは画像のサーバーから Referer なしで読み込みます。
  5. キャラ自動マッチ（初期状態はオフ）：設定でオンにしたときだけ動きます。タイトルとアーティストは内蔵のルール表を使って端末内で照合し、どこにも送りません。マッチしたキャラがまだダウンロードされていない場合は、assets.petdex.dev からキャラ一覧（1 日 1 回まで）とそのキャラ 1 体分の素材を取得します。個人データは含みませんが、Petdex のサーバーには IP アドレスと、どのキャラがダウンロードされたかが見えるため、それに関係する内容を再生していることがおおよそ推測できます。ダウンロード済みのキャラが再びマッチしても通信は発生しません。

内蔵キャラと吹き出しの絵文字素材は拡張機能に同梱されており、表示時に通信はしません。

自分で描いたキャラの共有では、拡張機能が自動で何かを送ることはありません。ダウンロードフォルダに zip を保存し、クリックしたときだけ GitHub のページかメールアプリを開きます。送るかどうかはあなたが決めます。採用された場合、キャラの名前・クレジット名・スプライトシートがプロジェクトの GitHub リポジトリで CC BY 4.0 として公開されます。

権限について

  • storage：上の表の設定やデータを保存するため。
  • alarms：1 時間に 1 回バックグラウンドを起動し、リモートライブラリの更新が必要か確認するため。
  • すべてのサイトでのコンテンツスクリプト：どのページにもキャラを表示し、そのページのメディアの状態を読み取り、あなたが押した操作を実行するため。
  • 任意の https://*/*・http://*/* ホスト権限：初期状態では付与されません。必要になったときに、特定のサイトについてだけ許可を求めます。
    • クロスオリジンアクセスに対応していないカスタムライブラリを追加するとき：そのサイトだけ。
    • モデルサービスを接続するとき：その API とログイン用のサーバー（例：api.openai.com、auth.openai.com）。サブスクリプションのログインでは、ログイン後のリダイレクト先を読み取って自動でログインを完了するため、localhost / 127.0.0.1 も求めます（拡張機能がローカルでポートを開くことはありません）。
    • カスタムのモデルエンドポイントを追加するとき：そのアドレスだけ（ローカルサーバーは通常 http://localhost）。

データの削除

chrome://extensions で拡張機能を削除すると、保存したデータはすべて消えます。設定ページから分類キャッシュの消去や、インポートしたキャラの削除もできます。

隐私政策

最后更新：2026-10-11

Kobutai 小舞台是一个开源浏览器扩展。开发者不运营任何服务器，不收集、不接收、不出售任何用户数据。扩展没有统计、埋点或广告。

浮层位置和大小（按网站）、隐藏角色的网站列表、界面语言、分享角色时的署名记住你的设置chrome.storage.local（本机）

扩展不读取网页正文、表单、Cookie、浏览历史，也不会把完整网址发给任何人。

什么时候会联网，发给谁

只有下面几种情况会发出网络请求，而且都直接从你的浏览器发出：

  1. AI 识别（默认关闭）：只有你在「AI 识别」页连接了你自己的模型服务商（API key、订阅登录或自定义端点）并启用时，才可能发送：正在播放的内容默认由扩展自带的小模型在本机识别，不发送任何数据；只有遇到内置模型没把握的新内容，才会把这一条内容的标题、作者、网站域名直接发给你选的那个服务商（例如 OpenAI、Anthropic、DeepSeek、OpenRouter，或你自己的 Ollama 服务器），用来判断类型和曲风。适用该服务商的隐私政策。结果缓存在本机，同一内容不会重复发送。
    • 连接时：订阅登录会打开服务商的登录页面，并和服务商的授权服务器交换令牌；令牌过期时扩展会自动向该服务商刷新。
  2. 远程角色库：扩展每 12 小时（失败后 30 分钟）从你订阅的角色库下载角色（默认是本项目 GitHub 仓库的 library/，地址为 raw.githubusercontent.com）。角色库里的 pack.json 可以引用其他 https 地址上的素材，这时也会访问那些地址。请求不包含任何个人数据，但对方服务器会像访问任何网站一样看到你的 IP 地址。
  3. Petdex 导入：只有你在设置页主动搜索或导入时，才会访问 assets.petdex.dev 下载宠物列表，再从列表里给出的 https 地址下载你选中的那个宠物的素材。
  4. 封面图：控制条会显示正在播放内容的封面图（由播放网站提供，仅限 https）。显示时浏览器会从该图片所在服务器加载图片，且不带 Referer。
  5. 自动匹配角色（默认关闭）：只有你在设置页打开时才生效。扩展在本机用内置的规则表检查标题和作者里有没有已知的角色、作品或热梗，标题和作者不会发给任何人。命中、且对应的角色还没有下载过时，会从 assets.petdex.dev 下载宠物列表（每天最多一次）和那一个角色的素材。请求不包含任何个人数据，但 Petdex 的服务器会看到你的 IP 地址，以及下载的是哪个角色，从中可以大致推断你在播放和它有关的内容。已经下载过的角色再次命中时不会联网。

内置角色和表情气泡的表情素材都打包在扩展里，显示它们不联网。

分享自己画的角色时扩展本身不发送任何东西：它把 zip 保存到你的下载文件夹，你点了才会打开 GitHub 页面或邮件应用，发不发由你决定。被选中后，角色名、你的署名和精灵图会以 CC BY 4.0 公开在本项目的 GitHub 仓库里。

权限说明

  • storage：保存上面表格里的设置和数据。
  • alarms：每小时唤醒一次后台，检查远程角色库是否需要更新。
  • 在所有网站运行内容脚本：用来在任意网页上显示悬浮角色、读取该页面正在播放的媒体状态并执行你点的播放控制。
  • 可选的 https://*/*、http://*/* 主机权限：默认不授予，用到时只针对具体网站向你申请：
    • 添加一个不支持跨域访问的自定义角色库时，申请那一个网站；
    • 连接一个模型服务商时，申请它的 API 和登录服务器（例如 api.openai.com、auth.openai.com）；订阅登录还会申请 localhost / 127.0.0.1，用来读取登录完成后跳转到的本机地址、自动完成登录（扩展不会在本机开端口）；
    • 添加自定义模型端点时，申请那一个地址（本地服务通常是 http://localhost）。

删除数据

在 chrome://extensions 移除扩展即可删除它保存的全部数据。设置页里也可以清空识别缓存、删除导入的角色。
