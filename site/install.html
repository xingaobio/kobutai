Install Kobutai

Chrome · Edge · other browsers · Windows

The easiest way is the store for your browser: one click, and it updates itself. Use the zip only for browsers without a store listing, or when you can't reach a store.

Chrome

  1. Open Kobutai in the Chrome Web Store.
  2. Click Add to Chrome, then Add extension.
  3. Play a song on YouTube or Spotify: the character appears in the bottom-right corner. Pin the toolbar icon (the puzzle piece → pin) for the mini player.

Edge

  1. Open Kobutai in Microsoft Edge Add-ons. This also works in mainland China.
  2. Click Get, then Add extension.

Other browsers (360, QQ Browser, Brave, Opera, Vivaldi…)

  1. Download kobutai-extension.zip and unzip it. Keep the unzipped folder somewhere it won't be deleted: the browser loads the extension from it.
  2. Open the extensions page: type chrome://extensions in the address bar (Brave: brave://extensions, Opera: opera://extensions). In 360 or QQ Browser, open the menu → Extensions / Extension manager.
  3. Turn on Developer mode (usually a switch at the top right).
  4. Click Load unpacked and choose the unzipped folder (the one that contains manifest.json).

Good to know:

  • Manual installs don't update themselves. To update, download the new zip from Releases, replace the folder's contents and press the reload button on the extensions page. Your album and settings are kept.
  • Some browsers show a reminder about developer-mode extensions when they start; that's expected.
  • Browsers with an older engine may not offer every feature (for example the picture-in-picture window); the character and the controls still work.

Windows app (preview)

  1. Download kobutai-windows-setup.exe (or the .msi if your company manages installs).
  2. Run it. The installer isn't signed yet, so Windows may show "Windows protected your PC": click More info → Run anyway. Your browser may also ask whether to keep the download; choose Keep.
  3. When it's done, Kobutai sits in the system tray (bottom right, next to the clock). Play something in any app that shows in Windows' media controls (Spotify, a browser tab, a media player) and the character appears on your desktop.

It's an early preview: AI recognition, the remote character library and settings windows aren't in it yet. Requires Windows 10 or 11. To uninstall: Settings → Apps → Kobutai → Uninstall.

Kobutai のインストール

Chrome・Edge・ほかのブラウザ・Windows

いちばん簡単なのは、使っているブラウザのストアから入れる方法です。ワンクリックで、自動で更新されます。zip はストアがないブラウザや、ストアにつながらないときだけ使ってください。

Chrome

  1. Chrome ウェブストアの Kobutai を開きます。
  2. 「Chrome に追加」→「拡張機能を追加」をクリック。
  3. YouTube や Spotify で曲を再生すると、右下にキャラが出てきます。ツールバーのパズルのアイコンからピン留めすると、ミニプレーヤーが使えます。

Edge

  1. Microsoft Edge アドオンの Kobutai を開きます。中国本土からも利用できます。
  2. 「インストール」→「拡張機能の追加」をクリック。

ほかのブラウザ（360、QQ ブラウザ、Brave、Opera、Vivaldi など）

  1. kobutai-extension.zip をダウンロードして解凍します。ブラウザはこのフォルダから拡張機能を読み込むので、消さない場所に置いてください。
  2. 拡張機能のページを開きます。アドレスバーに chrome://extensions と入力（Brave は brave://extensions、Opera は opera://extensions）。360 や QQ ブラウザはメニュー →「拡張機能」/「拡張機能の管理」。
  3. 右上などにある「デベロッパー モード」をオンにします。
  4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、解凍したフォルダ（manifest.json が入っているフォルダ）を選びます。

注意：

  • 手動インストールは自動更新されません。新しい版が出たら Releases から zip をダウンロードしてフォルダの中身を入れ替え、拡張機能のページで再読み込みボタンを押してください。図鑑と設定はそのまま残ります。
  • ブラウザの起動時に「デベロッパー モードの拡張機能」についての通知が出ることがありますが、問題ありません。
  • エンジンが古いブラウザでは、ピクチャー・イン・ピクチャーなど一部の機能が使えないことがあります。キャラの表示と再生の操作は使えます。

Windows 版（プレビュー）

  1. kobutai-windows-setup.exe をダウンロードします（会社の PC など MSI が必要な場合は .msi）。
  2. 実行します。インストーラーはまだ署名されていないため、「Windows によって PC が保護されました」と表示されることがあります。「詳細情報」→「実行」をクリックしてください。ブラウザがダウンロードを保存するか確認してきたら「保存」を選びます。
  3. インストールが終わると、Kobutai は通知領域（右下の時計の横）に入ります。Windows のメディア操作に表示されるアプリ（Spotify、ブラウザのタブ、メディアプレーヤーなど）で再生すると、デスクトップにキャラが出てきます。

先行プレビューのため、AI 判定・リモートのキャラライブラリ・設定画面はまだありません。Windows 10 / 11 が必要です。アンインストール：設定 → アプリ → Kobutai → アンインストール。

GitHub で issue を作るか、xingaouk@gmail.com までメールしてください。

安装 Kobutai

Chrome · Edge · 其他浏览器 · Windows

最简单的是从你所用浏览器的商店安装：一键完成，以后自动更新。只有在浏览器没有商店、或者打不开商店的时候，才需要用 zip 手动安装。

Chrome

  1. 打开 Chrome 应用商店里的 Kobutai。
  2. 点"添加至 Chrome"，再点"添加扩展程序"。
  3. 去 YouTube 或 Spotify 放一首歌，右下角就会出现角色。点工具栏的拼图图标把 Kobutai 固定出来，就能用迷你播放器。

Edge

  1. 打开 Microsoft Edge 加载项商店里的 Kobutai，国内可以正常访问。
  2. 点"获取"，再点"添加扩展"。

其他浏览器（360、QQ 浏览器、Brave、Opera、Vivaldi 等）

  1. 下载 kobutai-extension.zip 并解压。浏览器会从这个文件夹加载扩展，请放在不会被删掉的地方。
  2. 打开扩展管理页：在地址栏输入 chrome://extensions（Brave 是 brave://extensions，Opera 是 opera://extensions）。360、QQ 浏览器在菜单 →"扩展"/"扩展管理"。
  3. 打开右上角的"开发者模式"。
  4. 点"加载已解压的扩展程序"，选择解压出来的文件夹（里面有 manifest.json 的那个）。

注意：

  • 手动安装不会自动更新。有新版本时，到 Releases 下载新的 zip，替换文件夹里的内容，再在扩展管理页点"重新加载"。图鉴和设置都会保留。
  • 有些浏览器启动时会提醒"开发者模式下的扩展"，这是正常的。
  • 内核较旧的浏览器可能用不了部分功能（例如画中画悬浮窗），角色和播放控制仍然可以用。

Windows 版（预览）

  1. 下载 kobutai-windows-setup.exe（公司电脑需要 MSI 的话，下载 .msi）。
  2. 运行安装程序。安装包还没有签名，Windows 可能提示"Windows 已保护你的电脑"：点"更多信息"→"仍要运行"。浏览器如果询问是否保留下载的文件，选"保留"。
  3. 装好后，Kobutai 会出现在任务栏右下角时钟旁边的通知区域。在任何会出现在 Windows 媒体控制里的应用（Spotify、浏览器标签页、播放器等）里播放，角色就会出现在桌面上。

这是早期预览版，还没有 AI 识别、远程角色库和设置窗口。需要 Windows 10 或 11。卸载：设置 → 应用 → Kobutai → 卸载。
