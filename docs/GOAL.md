# GOAL：M1 → M3 循环推进

这个文件是 loop 的**唯一状态源**。每一轮迭代都先读它，再改它。

## 循环协议（每轮迭代）

1. 读本文件，找到**当前里程碑**下第一个未勾选的任务。
2. 实现该任务。保持小步提交：每个任务结束时 `npm run check` 通过（类型检查 + 单元测试 + 构建）。
3. 勾选任务，在"迭代日志"里追加一行，然后 git commit。
4. 当前里程碑的任务全部勾选后，进入**验收**：
   - 派一个 **Fable 5.1**（Agent `model: "fable"`）验收代理。它只读，对照本里程碑的"验收标准"逐条检查：读代码、跑命令、跑测试。
   - 它返回逐条的 PASS/FAIL 和问题清单。
   - 全部 PASS：把里程碑标记为 ✅，进入下一个里程碑。
   - 有 FAIL：把问题追加成本里程碑的新任务，继续循环。
5. M3 验收通过后，结束 loop。
6. 如果遇到必须由用户决定的问题，或连续 3 轮在同一处失败：在"阻塞"里写清楚，停止 loop，等待用户。
