# 角色台词（气泡对话）

> **状态：已实现（2026-10-22）。** 代码在 `src/lib/dialogue/`，气泡在 `src/components/Bubble.svelte`。台词源文件在 `docs/characters/lines/`（`zh.md`、`en.md`、`ja.md`），用 `python3 scripts/lines2json.py` 检查并导出为 `src/lib/dialogue/lines.json`。

内置角色除了表情和颜文字，还会在气泡里说一句符合人设的话：舒缓的歌说"好舒服…"，动感的歌说"这首太燃了！！"，被戳了会有反应。台词跟着界面语言走，中、英、日三种语言都有。日文和英文不是逐句翻译，而是按每个角色的口吻重新写的。

## 一、原则

1. **台词全部由人写好、审过。AI 只选情绪标签，不写字。** 用户看到的每一句话都在台词库里。
2. **宁可不说，不能说错。** 识别没把握时只说通用台词（"好听～"），不说"感觉要睡着了"这种带判断的话。
3. **少说。** 跟播放有关的台词有冷却时间；冷却中或用户调成"安静"时，气泡照旧显示表情或颜文字。
4. **人设优先。** 每个角色有自己的口癖和语气，同一个事件，不同角色说出来要不一样。
5. **只有内置角色说话。** 用户导入的角色、Petdex 角色和远程角色库里的角色只显示表情，免得说出不符合原作人设的话。还没写专属台词的内置角色（乐酷、薇奥、艾莉亚、应援酱、听听）先用全局库。

## 二、事件

| key | 什么时候说 | 受冷却限制 | 说不了时 |
|---|---|---|---|
| `playing.<情绪>` | 新内容开始、抽到角色后；长时间播放时的"中途换表情"里约一半是台词 | 是 | 表情 / 颜文字 |
| `late_night` | 0～4 点第一次开始播放新内容时，代替 `playing.*`（每晚一次） | 是 | 改说 `playing.*` |
| `paused` | 暂停时 | 是 | 😴 / (｡-ω-)zzZ |
| `resumed` | 暂停超过 30 秒后继续播放同一个内容 | 是 | 不显示 |
| `long_play` | 同一个内容实际播放满 60 分钟，之后每 60 分钟（借"中途换表情"的时机） | 是 | 改说 `playing.*` 或表情 |
| `appear` | "换一次"换来的新角色登场 | 否 | 🥳 |
| `click` | 用户点角色 | 否 | 不显示 |
| `click.many` | 5 秒内点第 3 次及以上 | 否 | 改说 `click` |
| `repeat` | 同一首播到第 2 遍 | — | **台词已写，还没接**（要先能识别"重播"） |
| `idle` | 长时间没有播放 | — | **台词已写，还没接**（没声音 5 分钟后角色会收起，目前只在"一直显示"时有意义） |

隐藏角色（月白、NOVA、莓莓）的台词也已写好，等出现条件的代码加上就能用；登场时只说 `appear`，不再叠加触发它的那个事件。

## 三、情绪

| 情绪 | 内容 | 来源 |
|---|---|---|
| `calm` 舒缓 | 音乐 | 曲风 lofi、classical |
| `hype` 动感 | 音乐 | 曲风 rock、electronic、hiphop |
| `bright` 明亮 | 音乐 | 曲风 jpop、anime、western-pop |
| `sad` 伤感 | 音乐 | **只来自 AI**，分类器判断不了 |
| `any` 通用 | 音乐 | 曲风 cpop、other，或者曲风未知 |
| `ent` / `info` | 视频 | `vclass` |
| `live` | 直播 | `type` |
| `podcast` | 播客 | `type` |

- 本地分类器没把握时本来就不给曲风（`genre = null`），这时情绪是 `any`，只说不分情绪的台词。
- 用户连接了 AI 时，AI 在同一次调用里多返回一个 `mood`（见第八节）。有 `mood` 就以它为准，这样能分出华语里的抒情歌和快歌。

## 四、回退顺序

以 `playing.calm` 为例，逐级回退，最后一级都没有就改显示表情：

1. 本角色的 `playing.calm`
2. 本角色的 `playing.any`
3. 全局库的 `playing.calm`
4. 全局库的 `playing.any`

其他事件只有第 1、3 步（`click.many` 会再找 `click`）。

## 五、频率和显示

设置页"表情气泡"一栏里的"角色说话"：

| 设置 | 跟播放有关的台词 | 出场、点击 |
|---|---|---|
| 话多 | 最多每 1 分钟一句 | 每次 |
| 偶尔说（默认） | 最多每 3 分钟一句 | 每次 |
| 安静 | 不说 | 每次 |
| 不说话 | 不说 | 不说 |

- 关掉"表情气泡"时台词也不显示。
- **不重复**：每组台词记住最近说过的 3 句（台词不够 4 句时记住"句数 − 1"句），随机时跳过它们。
- **显示时长**：1.5 秒 + 每字 0.12 秒，限制在 2.5～5 秒。
- 每个标签页各自挑台词，所以不同标签页上可能说得不一样。

## 六、气泡样式

- 和表情气泡同一个位置、同一种白底细边框，做成宽度跟着文字走的圆角贴纸，按台词内容固定歪 −2°～2°。
- 最宽约 170 px（角色放大时跟着变宽），最多显示 2～3 行；两行时向上长，不挡角色的脸。日文按词组换行（`word-break: auto-phrase`），两行时长度尽量平均。
- 鼠标悬停、控制条在角色上方打开时，气泡移到角色头部旁边，免得被控制条挡住（点角色时的台词尤其需要）。
- 台词里的 `{k}` 显示为角色的代表颜文字（`SIGNATURE_KAOMOJI`）。
- 系统开了"减少动态效果"时不做弹出动画。

## 七、写台词的规则

**格式**（源文件开头也有说明）

```
## rina 莉娜            ← 角色 id（和角色包 id 一致）+ 名字
> 口吻说明             ← 脚本忽略，给写台词的人看
### playing.hype       ← 一组台词
- 这首太燃了！！
- 就是这个劲！{k}
```

- 长度：不算 `{k}`，中文最多 16 字、日文最多 18 字（全角算 1，半角算 0.5）；英文按半角算，约 40 个字符。
- 数量：`appear`、`click`、`playing.any` 至少 5 句，其他组至少 3 句。
- 必须有：`appear`、`click`、`playing.any`、`paused`。
- 三种语言要有同一批角色，否则换语言后某个角色会突然不说话。脚本会检查。

**禁止**

- 歌名、歌手名、书名号和引号括起的作品名，以及**任何歌词或台词引用**（版权）。
- 评价真人。
- 贬低正在播放的内容（"好吵""难听""うるさい""noisy"）。角色可以困、可以被吓到，但不说内容不好。
- 让人愧疚或依赖的话（"你不陪我我会难过"）、恋爱暗示。
- 说教和催促（"快去睡觉！"）。提醒喝水、伸懒腰可以，语气要轻。
- "记录""数据"之类的词，免得让人以为在收集信息。

**日文和英文**：按角色口吻写口语，不逐句直译。每个角色的日文一人称、口癖写在 `ja.md` 各角色开头的说明里（例如リナ用「あたし」「〜じゃん！」，ネイ几个字就结束）。中文里的习惯说法要换成对应的说法，例如"熬夜要变熊猫"在日文里是「クマできるよ」，英文是 "Panda eyes incoming~"。

## 八、AI 接入的约束

**现在的做法：AI 只返回情绪标签。** 用户连接自己的模型时，打标签的那次调用（`src/lib/tagging/ai.ts`）多了一个可选字段 `mood`，取值只能是 `calm`、`hype`、`bright`、`sad` 或 `none`：

- 走工具调用的 JSON Schema 枚举，模型只能选，不能写字。
- 扩展里再校验一遍：不是这四个值之一就丢掉，台词改按曲风选。
- 不增加请求次数，发送的仍然只有标题、作者、域名；`mood` 和其他标签一起按内容缓存。
- AI 返回的任何文字都**不会**显示给用户。情绪判断错了，最坏的结果是说了一句不太贴切的话。

**以后再考虑：AI 现写台词。** 收益不大，暂不做。真要做至少需要：提示词给出人设和示例、只输出 JSON；扩展里硬性校验长度、歌名、歌手名、链接、敏感词和语言，任何一条不通过就改用固定台词；禁止引用歌词；默认关闭并写进 `PRIVACY.md`。

## 九、文件

| 文件 | 内容 |
|---|---|
| `docs/characters/DIALOGUE.md` | 本规范 |
| `docs/characters/lines/zh.md`、`en.md`、`ja.md` | 台词源文件，人来改 |
| `scripts/lines2json.py` | 检查格式、长度、禁用词、三种语言的角色是否一致，导出 JSON |
| `src/lib/dialogue/lines.json` | 导出结果，随扩展打包（不要手改） |
| `src/lib/dialogue/dialogue.ts` | 情绪判断、回退、冷却、不重复、代表颜文字 |
| `src/lib/dialogue/dialogue.test.ts` | 单元测试，也会检查 `lines.json` 的长度和格式 |

改完台词：

```
python3 scripts/lines2json.py          # 检查并导出
python3 scripts/lines2json.py --check  # 只检查
npm test
```

以后给其他角色（第二批、隐藏角色之外的新角色）写台词：在三个源文件里各加一节同样 id 的 `## <id>`，再跑一次脚本。社区投稿的角色包暂时不支持自带台词。
