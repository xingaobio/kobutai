# 角色台词库（中文）

> 格式：`## <角色 id> 名字` 开始一个角色，`### <key>` 开始一组台词，`- ` 开头的每一行是一句。其他行（比如 `>` 开头的人设说明）脚本会忽略。
> `{k}` 显示为角色的代表颜文字。规则见 `docs/characters/DIALOGUE.md` 第七节。改完运行 `python3 scripts/lines2json.py`。
